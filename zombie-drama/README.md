# ย้อนเวลา ก่อนซอมบี้บุกเตรียมพัฒน์ — EP.1

ละครแอนิเมชันสั้นแนวตั้ง (9:16, 1080×1920, 82 วินาที) สไตล์ซีรีส์ AI ใน TikTok

**เรื่องย่อ:** ภูมิ นักเรียน ม.5 ตายในโลกที่ซอมบี้ครองเมือง แล้วตื่นขึ้นมาในห้องเรียนอีกครั้ง
ในเช้าวันจันทร์ที่ 10 มิ.ย. ซึ่งเป็นวันที่การระบาดเริ่มต้น เหลือเวลาอีก 3 ชั่วโมง
และไม่มีใครเชื่อเขาเลย… นอกจากคนลึกลับบนดาดฟ้าที่ *จำได้เหมือนกัน*

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `zombie-triampat-ep1.mp4` | วิดีโอพร้อมอัปโหลด TikTok (H.264 + AAC มีเสียงประกอบ) |
| `index.html` | ตัวเล่นแบบโต้ตอบ เปิดในเบราว์เซอร์แล้วแตะเพื่อเล่น (กด Space เพื่อหยุด/เล่นต่อ) |
| `export.js` | เรนเดอร์ `index.html` ออกมาเป็น MP4 อีกครั้งหลังแก้ไข |

## ฉาก

1. **ไทม์ไลน์เดิม** — โรงเรียนกำลังไฟไหม้ มิ้นท์ตายในอ้อมแขนภูมิ → แฟลชย้อนเวลา
2. **ไตเติล** — ย้อนเวลา ก่อนซอมบี้บุก เตรียมพัฒน์ EP.1
3. **หน้าประตูโรงเรียน** — เช้าวันจันทร์ธรรมดา
4. **ห้อง ม.5/3** — ภูมิตื่น เห็นวันที่บนกระดาน เห็นมิ้นท์ยังมีชีวิต แล้วเริ่มนับถอยหลัง
5. **ไม่มีใครเชื่อ** — ครูสมศรีกับเพื่อนหัวเราะ แล้วข่าวด่วนก็เด้งขึ้นมา
6. **11:00 น.** — นาฬิกาเดินเร็วจนถึงเวลาเกิดเหตุ
7. **โรงอาหาร** — เต้ไอ ล้มลง แล้วลุกขึ้นมาเป็นซอมบี้
8. **ทางเดิน** — ภูมิฉีดถังดับเพลิงใส่ซอมบี้ และรู้ทางหนีไปห้องสมุดชั้น 4
9. **ดาดฟ้าตอนพระอาทิตย์ตก** — มิ้นท์ถามว่าเขาเป็นใคร… แล้วชายใส่ฮู้ดก็พูดว่า “ยินดีต้อนรับกลับมานะ… ภูมิ”
10. **ฉากจบ** — ทีเซอร์ EP.2 และขอให้กดติดตาม

## วิธีแก้ไขและเรนเดอร์ใหม่

ทุกอย่างวาดด้วยโค้ดใน `index.html`:

- บทพูด: แก้ใน array `SUBS`
- ฉาก: แก้ในบล็อก `scene(...)`
- เสียง: แก้ใน `buildAudio()` ซึ่งสังเคราะห์เสียงทั้งหมดด้วย Web Audio จึงไม่มีปัญหาลิขสิทธิ์

```bash
node export.js                 # ต้องมี Playwright (Chromium) และ ffmpeg
node export.js out.mp4 60      # เลือกชื่อไฟล์และ fps เองได้
```

> เรื่องนี้เป็นเรื่องสมมติ ตัวละครและเหตุการณ์ไม่มีอยู่จริง ไม่ได้ใช้โลโก้หรือตราสัญลักษณ์ของโรงเรียน
