## EP.1 — ย้อนเวลา

ภูมิ นักเรียน ม.5 ตายในโลกที่ซอมบี้ครองเมือง แล้วตื่นขึ้นมาในห้องเรียนอีกครั้ง
ในเช้าวันจันทร์ที่ 10 มิ.ย. ซึ่งเป็นวันที่การระบาดเริ่มต้น เหลือเวลาอีก 3 ชั่วโมง และไม่มีใครเชื่อเขาเลย

1. **ไทม์ไลน์เดิม** — โรงเรียนกำลังไฟไหม้ มิ้นท์ตายในอ้อมแขนภูมิ → แฟลชย้อนเวลา
2. **ห้อง ม.5/3** — ภูมิตื่น เห็นวันที่บนกระดาน เห็นมิ้นท์ยังมีชีวิต แล้วเริ่มนับถอยหลัง
3. **ไม่มีใครเชื่อ** — ครูสมศรีกับเพื่อนหัวเราะ แล้วข่าวด่วนก็เด้งขึ้นมา
4. **11:00 น. ที่โรงอาหาร** — เต้ล้มลงแล้วลุกขึ้นมาเป็นซอมบี้
5. **ทางเดิน** — ภูมิฉีดถังดับเพลิงใส่ซอมบี้ แล้วพาทุกคนหนีไปห้องสมุดชั้น 4
6. **ดาดฟ้า** — ชายใส่ฮู้ดพูดว่า “ยินดีต้อนรับกลับมานะ… ภูมิ”

## EP.2 — คนที่ย้อนเวลากลับมา ไม่ได้มีแค่ฉัน

1. **ที่ผ่านมา** — ย้อนฉากหักมุมบนดาดฟ้า
2. **ดาดฟ้า** — ชายใส่ฮู้ดกระโดดลงจากแท็งก์น้ำ แล้วเปิดเผยตัวว่าเป็น **ธาม ม.6/1** ที่ย้อนเวลามาแล้ว *3 ครั้ง*
   เขาบอกว่า “คนที่พยายามช่วยทุกคน จะตายก่อนเสมอ”
3. **ห้องสมุดตอนกลางคืน** — ธามวาดแผนที่บนไวต์บอร์ด เชื้อเริ่มต้นที่ **แล็บชีวะ ตึก 3**
   และยิ่งเปลี่ยนอดีตมากเท่าไหร่ ซอมบี้ก็ยิ่งเปลี่ยนตาม
4. **ปัง! ปัง!** — มีคนทุบประตูเหล็ก แล้วซอมบี้ที่ *ปีนกำแพงได้* ก็โผล่มาที่หน้าต่าง
5. **เพล้ง!!** — ซอมบี้พังกระจกเข้ามา ภูมิเข้าไปขวาง ธามหวดไม้เบสบอลจนซอมบี้กระเด็นออกไป แต่มิ้นท์ **โดนข่วน**
6. **ความลับของมิ้นท์** — เธอซ่อนแผลไว้แล้วยิ้มว่า “ไม่เป็นไรหรอก”
7. **กฎของธาม** — “ถ้ามีใครโดนกัดหรือโดนข่วน… นายต้องเป็นคนจัดการเอง”
8. **ตอนจบค้างคา** — ตาของมิ้นท์กะพริบเป็นสีแดง แล้วตัวนับ “ก่อนกลายเป็นซอมบี้ 11:59:59” ก็เริ่มเดิน
9. **ฉากจบ** — ทีเซอร์ EP.3 “ถ้าคนที่ต้องจัดการ… คือคนที่ฉันรัก”

## วิธีแก้ไขและเรนเดอร์ใหม่

แต่ละตอนเป็นไฟล์ HTML ไฟล์เดียวที่วาดทุกอย่างด้วยโค้ด:

- บทพูด: แก้ใน array `SUBS`
- ฉาก: แก้ในบล็อก `scene(...)`
- เสียง: แก้ใน `buildAudio()` ซึ่งสังเคราะห์เสียงทั้งหมดด้วย Web Audio จึงไม่มีปัญหาลิขสิทธิ์

```bash
node export.js                 # EP.1 → zombie-triampat-ep1.mp4 (ต้องมี Playwright/Chromium และ ffmpeg)
node export.js ep2.html        # EP.2 → zombie-triampat-ep2.mp4
node export.js ep2.html out.mp4 60   # เลือกชื่อไฟล์และ fps เองได้
```

> เรื่องนี้เป็นเรื่องสมมติ ตัวละครและเหตุการณ์ไม่มีอยู่จริง ไม่ได้ใช้โลโก้หรือตราสัญลักษณ์ของโรงเรียน
