## EP.1 — วันที่เราได้เจอกัน

1. **ความฝัน** — ถนนตอนกลางคืนกลางสายฝน เสียงปริศนาถามว่า “นายยังจะพยายามอีกงั้นเหรอ?” กันต์วิ่งตามฟิล์มแต่ไม่เคยทัน แล้วไฟหน้ารถก็พุ่งเข้ามา
2. **ห้องนอน** — แม่ปลุกในวันเปิดเทอม กันต์จำได้แค่ความรู้สึกว่ากำลังจะเสียใครบางคนไป (มีโปสเตอร์กลุ่มดาวคนคู่บนผนังเป็นการปูเรื่อง)
3. **ไตเติล** — ONE MORE DAY • แค่วันเดียวกับเธอ
4. **หน้าบ้านและหน้าซอย** — เรื่องหมวกกันน็อกกับแม่ แล้วเต้รออยู่หน้าซอย
5. **หน้าโรงเรียน** — จักรยานชนฟิล์มจนหนังสือกระจาย “นายขี่จักรยานหรือขี่รถถังเนี่ย?” เสียงของเธอเหมือนในความฝัน
6. **หอประชุม** — จับคู่ Buddy ได้ “กันต์ ห้อง 4/1… คู่กับ ฟิล์ม ห้อง 4/3”
7. **ลานโรงเรียน** — สองคนต่างก็อยากเปลี่ยนคู่ ส่วนแก๊งเพื่อนแอบพนันว่าจะอยู่ด้วยกันได้กี่วัน
8. **ห้องแล็บ** — ทะเลาะกันจนการทดลองพัง ครูสั่งให้ทำใหม่ทั้งหมด หลายชั่วโมงต่อมาก็ยอมคืนดีกัน “ครับ คุณครูฟิล์ม”
9. **กล้องโทรทรรศน์** — ส่องกลุ่มดาวคนคู่ (Gemini) แล้วสบตากันนานเกินไป
10. **ตอนจบ** — “ผมไม่รู้เลยว่า… เวลาของเรา เหลืออีกไม่มาก”

## เสียงพากย์ทำงานอย่างไร

- เสียงพากย์สร้างด้วยโมเดล TTS ภาษาไทยแบบออฟไลน์ **MMS Thai (VITS)** ของ Meta ที่รันผ่าน [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx) ไม่ต้องใช้บริการออนไลน์
- โมเดลมีเสียงต้นแบบแค่เสียงเดียว (ผู้ชาย) จึงสร้างเสียงของแต่ละตัวละครด้วยการปรับระดับเสียงและความเร็ว ตั้งค่าได้ใน `voices` ของ `script_ep1.json`
  - เสียงในใจของกันต์ใส่เสียงก้อง
  - ครูในหอประชุมใส่เอฟเฟกต์ลำโพง
  - เสียงปริศนาในฝันทำให้ทุ้มและมีเสียงสะท้อน
- `tools/voice.py` ทำงานตามลำดับนี้:
  1. พากย์ทุกบรรทัด
  2. คำนวณไทม์ไลน์จากความยาวเสียงจริง
  3. วัดความดังของเสียงทุก 1/30 วินาทีเพื่อใช้ทำ lip-sync
  4. ฝังไทม์ไลน์และเสียงพากย์ (MP3 แบบ base64) ลงใน `ep1.html` ระหว่าง `/*@@TIMELINE*/` กับ `/*@@END*/`
- เพลงประกอบและเสียงเอฟเฟกต์สังเคราะห์ด้วย Web Audio และเพลงจะเบาลงอัตโนมัติตอนตัวละครพูด

## แก้บทแล้วสร้างใหม่

```bash
# 1) ติดตั้งครั้งแรก
python3 -m venv .venv && .venv/bin/pip install -r tools/requirements.txt
mkdir -p tools/model && curl -L https://github.com/k2-fsa/sherpa-onnx/releases/download/tts-models/vits-mms-tha.tar.bz2 | tar -xj -C tools/model

# 2) แก้บทใน script_ep1.json (text = ซับที่แสดง, tts = คำอ่านถ้าต่างจากซับ เช่น ตัวเลขหรือคำภาษาอังกฤษ)
.venv/bin/python tools/voice.py script_ep1.json ep1.html

# 3) เรนเดอร์วิดีโอ (ต้องมี Playwright/Chromium และ ffmpeg)
node export.js                  # → one-more-day-ep1.mp4
```

ข้อจำกัดของโมเดล: อ่านเลขอารบิกได้ไม่ครบ อ่านภาษาอังกฤษไม่ได้ และอ่านไม้ยมก (ๆ) ไม่ได้
จึงต้องเขียนคำอ่านเป็นภาษาไทยไว้ในช่อง `tts` เช่น `"4/1"` → `"สี่ทับหนึ่ง"` และ `"Gemini"` → `"เจมิไน"`

> เรื่องสมมติ เสียงพากย์สร้างด้วย AI
